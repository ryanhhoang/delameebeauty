# DELAMEE – GitHub / SEO files

Upload these files to the SAME root folder as index.html:

- sitemap.xml
- robots.txt
- site.webmanifest

Expected public URLs:
- https://delamee.de/sitemap.xml
- https://delamee.de/robots.txt
- https://delamee.de/site.webmanifest

After deployment, submit `https://delamee.de/sitemap.xml` in Google Search Console.
